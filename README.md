# Biblioteca Digital — Andarilho e suas Sombras (base Sarab)

Site adaptado a partir do template enviado `sarab.rar`, mantendo a estrutura visual e os recursos Bootstrap do modelo, mas convertendo o conteúdo para uma biblioteca literária.

## Publicação no GitHub Pages
1. Envie todos os arquivos e pastas deste projeto para a raiz de um repositório GitHub.
2. Acesse Settings → Pages.
3. Em Build and deployment, escolha Deploy from a branch, branch `main`, pasta `/(root)` e salve.
4. Aguarde a URL de publicação.

## Vídeos
Na página `videos.html`, substitua `VIDEO_ID` pelo ID do vídeo do YouTube. Para vídeos adicionais, copie o bloco `<iframe>` e ajuste ID e título. O GitHub Pages é para hospedagem estática e não é recomendado para vídeos grandes; use YouTube, Vimeo ou outro serviço externo.

## Personalização
Edite `index.html`, `obras.html` e `videos.html`. Os textos são exemplos. Troque `contato@exemplo.com` por um e-mail real ou remova o botão.
